COMO ENVIAR AO GITHUB
1. Entre no repositório do site no GitHub.
2. Extraia o conteúdo do ZIP; envie os arquivos para a RAIZ do repositório, no mesmo nível do index.html atual.
3. Confirme a substituição do index.html anterior e dos arquivos de imagem com os mesmos nomes.
4. MANTENHA todos os outros arquivos existentes no repositório (incluindo eventuais páginas administrativas e de privacidade). Este ZIP só substitui o index.html e os arquivos de imagem usados nele.
5. Faça commit e confira a publicação no navegador, inclusive as imagens, os presentes e a confirmação de presença.

SEGURANÇA E FUNCIONALIDADES
O HTML foi mantido a partir do pacote anterior, que já incluía integração de pagamentos, RSVP e cartas para o futuro. Os blocos de JavaScript não foram modificados durante a montagem deste pacote.
